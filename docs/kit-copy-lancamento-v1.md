## 3. MANYCHAT — FLUXOS POR PALAVRA-CHAVE

## 4. WHATSAPP BUSINESS — ETIQUETAS + RESPOSTAS RÁPIDAS

**Etiquetas (funil):** 🟡 Novo lead → 🔵 Orçamento enviado → 🟢 Sinal pago → 🟣 Agendado → ❤️ Pós-evento → ⚪ Frio

**Respostas rápidas** (Configurações > Ferramentas comerciais > Respostas rápidas):

`/oi` — primeiro contato
```
Oi, {nome}! 💛 Que bom ter você por aqui. Me conta: qual é a ocasião (a dois, entre amigas, aniversário ou pedido) e que data você imagina? Já te passo as opções certinhas.
```

`/orcamento` — proposta
```
Perfeito, {nome}! Para {ocasião} no dia {data}, recomendo:

✨ *{Coleção} · {Tier}* — R$ {valor}
{duração} de experiência montada e desmontada por nós, incluindo: {3 itens principais}.
Horários: manhã · tarde · pôr do sol ⭐ · noite

Para garantir a data: 50% via Pix agora, saldo até 72h antes. Chuva? Remarcamos sem custo. Fechamos?
```

`/reserva` — fechamento
```
Maravilha! 🎉 Para reservar {data} às {hora}:
Pix: {chave} — R$ {valor do sinal} (50%)
Me manda o comprovante que já confirmo sua data e te envio todos os detalhes.
```

`/confirmacao` — pós-Pix
```
Reserva confirmada, {nome}! 💛
📅 {data}, {hora} ({duração})
📍 {local — enviaremos o pin exato na véspera}
💰 Saldo de R$ {valor} até {data − 3 dias}
🌧 Previsão ruim? A gente monitora e te avisa com antecedência para remarcar sem custo.
Qualquer ajuste (cores, plaquinha, adicionais), é só falar!
```

`/saldo` — lembrete (enviar em D−4)
```
Oi, {nome}! Falta pouco 🌅 Para deixar tudo pronto para {data}, o saldo de R$ {valor} pode ser pago via Pix até {data − 3 dias}: {chave}. Qualquer coisa, me chama!
```

`/vespera` — D−1
```
Amanhã é o dia! 💛 Confirmando: {hora}, neste ponto: {pin}. Chegue no horário que o cenário estará pronto te esperando. Leve só você (e protetor solar 😉). A gente cuida do resto.
```

`/pos` — 3–4h após o evento
```
{nome}! Esperamos que vocês tenham amado cada detalhe 🌅 Se puderem, marquem a gente (@descomplicaguaruja) nos stories e deixem uma avaliação rapidinha no Google: {link}. Significa o mundo para um negócio que está começando 💛
```

`/depoimento` — D+2
```
Oi, {nome}! Podemos usar algumas fotos do seu momento no nosso Instagram? Ajuda muito outros casais a se decidirem 🥹 (Se preferir sem rostos, a gente respeita!)
```

`/chuva` — remarcação
```
{nome}, a previsão para {data} não está nos ajudando 🌧 Como prometido: remarcamos sem nenhum custo. Tenho disponibilidade em {opção 1} e {opção 2} — qual prefere?
```

`/grupo5` — upsell grupos 5+
```
Para {n} pessoas, o formato que fica incrível é o *combo de 2 montagens lado a lado* — o dobro do cenário, todo mundo junto. Te passo o valor especial de combo?
```
